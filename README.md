# Claude — skills vidéo

Ce dépôt contient des skills pour fabriquer des vidéos avec Claude (Claude Code les charge automatiquement depuis `.claude/skills/`).

| Skill | À quoi ça sert |
|---|---|
| `remotion-official` | Créer des vidéos animées en code (React + Remotion) : titres, scènes, sous-titres, rendu MP4 |
| `ffmpeg` | Couper, convertir, compresser, extraire le son, redimensionner |
| `moviepy` | Assembler des clips et ajouter du texte en Python |
| `elevenlabs` | Voix off IA, effets sonores, musique (clé API ElevenLabs nécessaire) |
| `acestep` | Générer de la musique de fond |
| `video-design` | Couleurs, typo, mise en page 16:9 et 9:16, critique visuelle du rendu |
| `youtube-stats` | Suivre les vues, la rétention et ce qui marche sur la chaîne |

Source : [digitalsamba/claude-code-video-toolkit](https://github.com/digitalsamba/claude-code-video-toolkit) (licence MIT, voir `.claude/skills/LICENSE-digitalsamba-MIT`). Les skills Remotion viennent du dépôt officiel [remotion-dev/skills](https://github.com/remotion-dev/skills).
